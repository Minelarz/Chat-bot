# Minelarz Yapay Zeka

Türkçe odaklı, Azure OpenAI destekli yapay zeka sohbet asistanı.

Minelarz Yapay Zeka; doğal dilde sohbet, belge analizi, kod açıklama ve CV değerlendirme özellikleri sunan modern bir AI yardımcı uygulamasıdır.

---

## Özellikler

✅ Türkçe sohbet desteği

✅ Azure OpenAI entegrasyonu

✅ Kod açıklama ve yorumlama

✅ Belge analizi

✅ CV değerlendirme

✅ Modern web arayüzü

✅ Blazor tabanlı mimari

✅ Mobil uyumlu tasarım
